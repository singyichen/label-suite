# /speckit.tasks — DEPRECATED

> **Retired (ADR-033, issue #356).** OpenSpec is now the implementation/change workflow layer; per-feature `tasks.md` under `specs/` is no longer produced.

Do not run this command. Instead:

- Draft the change with `/opsx:propose` — the task breakdown goes into `openspec/changes/<change>/tasks.md`.
- The task granularity and TDD split rules in `.specify/templates/tasks-template.md` still apply to that `tasks.md`, but it is no longer generated by this command.
- See [ADR-033](../../docs/adr/033-openspec-change-workflow.md) and the CLAUDE.md SDD pipeline for the current flow.
