# Contributing

This repository is **not currently accepting external pull requests**.

## Why

- Label Suite is unpublished thesis research. The work in this repository must
  remain the original work of its author until the thesis is complete.
- The [LICENSE](LICENSE) is an all-rights-reserved research preview notice. It
  grants no inbound license and there is no Contributor License Agreement
  (CLA), so contributed code cannot be accepted on clear terms.

## What is welcome

- **Issue reports** (bugs, questions, feedback) are still welcome.
- **Code contributions** are planned for the open-source repository described
  in [ADR-036](docs/adr/036-oss-repository-split.md). It will have its own
  license and its own `CONTRIBUTING.md`; this file applies only to this
  repository.

## Citing

If you use or refer to this work, see [CITATION.cff](CITATION.cff).
