# 訪談指引：標記員受訪者

**角色說明**：執行標記任務的受訪者，依照任務負責人指派的任務完成 NLP 資料標記工作。

---

## 訪談前準備

- 確認受訪者近期有執行過標記工作
- 準備筆記本或錄音設備（徵得同意後）
- 預計時間：45–60 分鐘

---

## 一、暖身與背景（5–10 分鐘）

| 編號 | 問題 |
|------|------|
| A01 | 請簡單介紹你自己，目前在哪個實驗室協助標記工作？ |
| A02 | 你做標記工作多久了？大概每週花多少時間在上面？ |
| A03 | 你做過哪些類型的標記任務？（文本分類、命名實體、情感分析等） |
| A04 | 你目前使用什麼工具或方式完成標記？（Label Studio、Excel、自製工具等） |

---

## 二、任務接收與理解（10 分鐘）

| 編號 | 問題 |
|------|------|
| A05 | 研究生通常用什麼方式告訴你要做什麼任務？（口頭、LINE、email、系統通知） |
| A06 | 你如何知道任務的截止日期和優先順序？ |
| A07 | 任務說明清楚嗎？有沒有過看不懂規則、需要反覆詢問的經驗？ |
| A08 | 你希望任務說明以什麼形式呈現最清楚？（文字、範例、影片） |

---

## 三、標記作業流程（15 分鐘）

| 編號 | 問題 |
|------|------|
| A09 | 描述一下你平常一次標記工作的完整流程，從接到任務到完成提交。 |
| A10 | 在標記過程中最常遇到什麼困難？（介面操作、規則模糊、資料品質） |
| A11 | 你有沒有遇過標記到一半系統出問題或資料消失的情況？ |
| A12 | 你每次能標多少筆資料？有沒有數量上的壓力？ |
| A13 | 完成標記後，你如何提交成果？有沒有需要額外確認或回報的步驟？ |

---

## 四、進度與回饋（10 分鐘）

| 編號 | 問題 |
|------|------|
| A14 | 你目前怎麼知道自己的標記進度與剩餘工作量？ |
| A15 | 有沒有遇過進度統計不準確或任務狀態不清楚的情況？ |
| A16 | 你希望系統如何提醒你任務期限、退件或需要重標的資料？ |
| A17 | 你希望標記完成後能看到哪些回饋？例如完成率、審核結果或常見錯誤。 |

---

## 五、回饋與期望（10 分鐘）

| 編號 | 問題 |
|------|------|
| A18 | 你最希望標記系統改善哪一件事？ |
| A19 | 如果有一個介面能讓你看到自己的標記進度、審核回饋和任務狀態，你覺得有幫助嗎？ |
| A20 | 你有沒有看過讓你覺得「這個設計很好用」的系統或工具？是什麼讓你這樣覺得？ |
| A21 | 還有什麼事情你想補充，或是你認為我沒問到但很重要的？ |

---

## 訪談後注意事項

- 確認受訪者是否同意錄音及資料使用方式
- 記錄檔命名：`YYYY-MM-DD-annotator-P0X.md`
- 記錄重點：工具使用習慣、痛點關鍵詞、對進度與審核回饋的需求
