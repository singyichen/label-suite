# 訪談指引：管理員受訪者

**角色說明**：負責帳號、權限與平台治理的實驗室行政人員，是連結研究員與標記員的後台管理角色。

---

## 訪談前準備

- 確認受訪者負責過帳號、權限或平台治理相關作業
- 準備筆記本或錄音設備（徵得同意後）
- 預計時間：45–60 分鐘

---

## 一、暖身與背景（5–10 分鐘）

| 編號 | 問題 |
|------|------|
| AD01 | 請介紹你在實驗室中負責的主要職責，帳號與權限管理佔你工作多大比重？ |
| AD02 | 你目前同時管理幾位平台使用者？他們分別在做什麼類型的標記或審核工作？ |
| AD03 | 你目前用什麼工具管理帳號、角色與任務存取權限？ |
| AD04 | 這些工具是否能滿足你的需求？最讓你困擾的地方是什麼？ |

---

## 二、帳號與權限管理（10 分鐘）

| 編號 | 問題 |
|------|------|
| AD05 | 新成員加入平台時，你的標準作業流程是什麼？帳號如何開設？ |
| AD06 | 目前帳號管理是手動建立還是有系統輔助？遇到什麼問題？ |
| AD07 | 成員離開實驗室或不再參與任務時，帳號和資料怎麼處理？ |
| AD08 | 不同角色（研究員、審核員、標記員）的系統權限，你怎麼管理？有沒有遇過權限設定錯誤的問題？ |

---

## 三、權限與稽核（15 分鐘）

| 編號 | 問題 |
|------|------|
| AD09 | 你目前如何確認使用者只能看到自己被授權的任務與資料？ |
| AD10 | 權限異動需要留下哪些紀錄？多久會檢查一次？ |
| AD11 | 有沒有遇過權限設定錯誤或資料誤看的情況？怎麼解決？ |
| AD12 | 如果系統提供權限異動紀錄與帳號狀態歷程，你最需要看到哪些欄位？ |
| AD13 | 你希望稽核報表呈現什麼格式？（依使用者、依任務、依時間區間） |

---

## 四、任務治理與平台狀態（15 分鐘）

| 編號 | 問題 |
|------|------|
| AD14 | 你需要掌握哪些平台層級的任務狀態？ |
| AD15 | 當任務成員、審核員或專案負責人需要變更時，目前由誰處理？ |
| AD16 | 你希望系統如何提示異常狀態？例如停用帳號仍被指派到任務。 |
| AD17 | 有沒有遇過任務權限或成員狀態造成流程卡住的情況？原因是什麼？ |
| AD18 | 如果系統能提供平台治理儀表板，你希望有哪些人工確認步驟？ |

---

## 五、任務可見性與資料管控（10 分鐘）

| 編號 | 問題 |
|------|------|
| AD19 | 你需要掌握哪些關於標記任務進度的資訊？（完成率、逾期狀況） |
| AD20 | 不同計畫的資料，成員之間有沒有必要相互隔離？有沒有發生過資料混用的情況？ |
| AD21 | 如果標記員能自己看到所有開放任務並自行選擇，你擔心有什麼問題嗎？ |

---

## 六、回饋與期望（5–10 分鐘）

| 編號 | 問題 |
|------|------|
| AD22 | 你每個月在帳號與權限管理上花最多時間的事是什麼？最想被系統取代的手動作業是什麼？ |
| AD23 | 如果有一個整合帳號管理、權限稽核與平台狀態的後台，你希望它最重要的功能是什麼？ |
| AD24 | 新帳號採用「邀請制」（管理者發送邀請連結）還是「開放自行註冊」，你偏好哪一種？為什麼？ |
| AD25 | 還有什麼事情你想補充，或是你認為我沒問到但很重要的？ |

---

## 訪談後注意事項

- 確認受訪者是否同意錄音及資料使用方式
- 記錄檔命名：`YYYY-MM-DD-admin-P0X.md`
- 記錄重點：權限稽核需求、帳號邀請 vs 開放註冊偏好、平台治理儀表板需求
