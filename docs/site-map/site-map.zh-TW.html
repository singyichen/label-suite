Label Suite

網站地圖

Label Suite 是一個 NLP 資料標記平台。

存取層級: 公開 需登入 需任務角色 限管理員
網站結構
Label Suite
  • 帳號入口
    • 登入公開
      • 電子郵件 / 密碼
      • Google 帳號登入
    • 註冊公開
    • 忘記密碼公開
    • 重設密碼公開
  • 儀表板
    • 儀表板需登入
      • 一般使用者視圖
      • 專案負責人視圖
      • 標記者視圖
      • 審核者視圖
      • 超級管理員視圖
  • 任務管理
    • 任務列表需登入
    • 新增任務需登入
      • 步驟一 基本資料
      • 步驟二 標記設定檔
      • 步驟三 啟動設定
      • 步驟四 標記說明(選填)
    • 任務詳情需任務角色
      • 任務概覽
      • 成員管理
      • 標記進度
      • 標記結果
      • 工時紀錄
  • 標記作業
    • 標記清單需任務角色
    • 標記工作區需任務角色
      • 說明檔案
      • 歷程
  • 資料集分析
    • 資料集分析列表需任務角色
    • 資料集分析詳情需任務角色
      • 統計總覽
      • 品質監控
  • 系統管理
    • 使用者管理限管理員
    • 角色設定限管理員
  • 個人設定
    • 個人設定需登入
      • 個人資料
      • 變更電子郵件
      • 修改密碼
      • 通知設定
