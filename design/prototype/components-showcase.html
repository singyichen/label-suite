Error / Alert Banner

§Error / Alert Banner — 頁面層級錯誤的 inline 呈現（role="alert"）；動作結果回饋請用 Toast。

Toast

§Toast / UXC-07 — 頂部置中 z-toast、單一實例；Success 3s / Info 5s / Warning 8s 自動消失，Error 僅能手動關閉。點按以觸發真實行為。

Skeleton

§Skeleton — Variant A pulse（卡片/清單版面）與 Variant B shimmer（表單版面）；尺寸須貼合載入後內容以防 layout shift（UXC-08）。

Chip

Color Dot

§Color Dot — 三種尺寸：標準 20×20（4px 圓角方，表單實體類型列）/ 預覽 12×12 / 狀態圓點 .t-dot 8×8（IAA 門檻通過與否）；顏色一律以 inline style.background 套用。

Divider

§Divider — 水平線 / 文字分隔（僅登入頁 OAuth 與帳號登入之間）/ 清單分隔（divide-slate-100）；MASTER 僅提供 Tailwind 範例，此處以 token 對應呈現。

Accordion

§Accordion — 可折疊表單分區；點擊或 Enter / Space 切換，多面板可同時展開；header role="button" + aria-expanded，body role="region" 與 aria-controls 配對。

Progress Bar

§Progress Bar — 6px 藥丸軌道，fill 一律 --color-cta（無逐狀態色，狀態語意請搭配 Status Badge）；wrapper 帶 role="progressbar" 與 aria-value*。
