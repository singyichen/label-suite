本頁是 [spec.md](./spec.md)〈審核流程〉一節所列五張圖的彙整檢視，供 NoteCraft
一次讀完。**每張圖的唯一來源都是同層 `diagrams/*.html`**——本檔在建置期以
Vite 的 `?raw` 引用原檔並抽出其中的 `<svg>`，沒有複製任何一行圖形內容，
改圖只需要改 `.html`，本頁自動跟著變。

五張原檔皆各自使用 `arw` / `arw-ac` / `arw-sf` 三個相同的 marker id，
同一份文件內 `url(#id)` 是文件層級解析、會互相覆蓋，故 `svgOf()` 在
render 時替每張圖的 id 與其引用加上專屬前綴。

原檔的 `svg { width: 100%; min-width: 1200px; display: block; }` 寫在 `<head>`
而不是 `<svg>` 上，抽 `<svg>` 時會一併掉失；`svgOf()` 把它補回 `<svg>` 的 inline
`style`，外層再包一層 `overflow-x: auto`，讓圖維持原始尺寸並可橫向捲動，而不是
隨欄寬縮到說明文字看不清。

export const svgOf = (raw, ns) =>
  raw
    .slice(raw.indexOf('<svg'), raw.lastIndexOf('</svg>') + 6)
    .replace('<svg', '<svg style="width:100%;min-width:1200px;display:block"')
    .replace(/(?<![\w-])id="([^"]+)"/g, `id="${ns}-$1"`)
    .replace(/url\(#([^)]+)\)/g, `url(#${ns}-$1)`)
    .replace(
      /(?<![\w-])aria-(labelledby|describedby)="([^"]+)"/g,
      (_m, attr, ids) =>
        `aria-${attr}="${ids.trim().split(/\s+/).map((id) => `${ns}-${id}`).join(' ')}"`,
    );
